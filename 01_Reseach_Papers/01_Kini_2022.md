# Kini et al. (2022)

| Item | Required Information |
|---|---|
| **Paper Title** | *SQL Injection Detection and Prevention Using Aho-Corasick Pattern Matching Algorithm* |
| **Author(s)** | S. Kini, A. P. Patil, Pooja M., and A. Balasubramanyam |
| **Year** | 2022 |
| **Research Problem** | The study investigates the detection and prevention of SQL Injection (SQLi) attacks using pattern matching techniques. The main challenge is identifying malicious SQL injection patterns within input queries. |
| **Method / Technique** | Aho-Corasick pattern matching algorithm is used to detect SQL injection patterns by matching input against predefined malicious patterns. |
| **Dataset / Tools** | SQL injection-related input patterns and malicious SQL query patterns. The main technique used is the Aho-Corasick pattern matching algorithm. |
| **Main Findings** | The approach achieved **90.23% detection accuracy**, demonstrating that pattern matching can effectively detect known SQL injection patterns. |
| **Limitation** | The approach relies on a static list of predefined patterns. Therefore, it may have difficulty detecting new, modified, or obfuscated SQL injection attacks. |
| **Relevance to Proposed Research** | Provides a traditional SQLi detection baseline and demonstrates the limitation of fixed pattern-based detection. This supports the need for an ML-based approach that can learn patterns from data and potentially generalise across different datasets. |
