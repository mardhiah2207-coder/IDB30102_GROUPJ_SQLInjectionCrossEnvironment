# Kini et al. (2022)

## Paper Title
SQL Injection Detection and Prevention Using Aho-Corasick Pattern Matching Algorithm

## Author(s)
S. Kini, A. P. Patil, Pooja M., and A. Balasubramanyam

## Year
2022

## Research Problem
The study investigates the difficulty of detecting and preventing SQL Injection (SQLi) attacks using traditional security mechanisms. SQL injection payloads can contain different malicious patterns, making it necessary to identify suspicious SQL input efficiently.

## Method / Technique
The study uses the Aho-Corasick pattern matching algorithm to detect SQL injection attacks. The approach searches for predefined malicious SQL patterns and matches them against input queries.

## Dataset / Tools
The study uses SQL injection-related input patterns and malicious SQL query patterns for detection. The main technique used is the Aho-Corasick pattern matching algorithm.

## Main Findings
The proposed approach achieved a reported detection accuracy of 90.23%. The study demonstrates that pattern matching can provide a relatively simple and effective method for identifying known SQL injection patterns.

## Limitation
The approach depends on a predefined and static list of SQL injection patterns. Therefore, it may have difficulty detecting new, modified, obfuscated, or previously unseen SQL injection payloads.

## Relevance to Proposed Research
This study provides a useful baseline for traditional SQL injection detection. Its dependence on predefined patterns highlights the need for more adaptive approaches. The limitation supports the proposed research on machine learning-based SQL injection detection using Random Forest, which learns patterns from data rather than relying only on manually defined signatures.
