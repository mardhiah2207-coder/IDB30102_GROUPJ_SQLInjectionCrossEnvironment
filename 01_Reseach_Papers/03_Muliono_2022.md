# Muliono et al. (2022)

| Item | Required Information |
|---|---|
| **Paper Title** | Predicting Confidentiality, Integrity, and Availability from SQL Injection Payload |
| **Author(s)** | Y. Muliono, M. Y. Darus, C. R. Pardomuan, M. A. M. Ariffin, and A. Kurniawan |
| **Year** | 2022 |
| **Research Problem** | The study investigates how the impact of SQL Injection payloads on confidentiality, integrity, and availability (CIA) can be predicted to support security monitoring and SIEM prioritisation. |
| **Method / Technique** | The study uses an SVM classifier integrated with a SIEM system with the preprocessing that includes tokenization and Bag-of-Words (BoW). |
| **Dataset / Tools** | CSIC 2010 dataset and SQLMap-generated payloads were used with the use of SVM, SIEM, SQLMap, scikit-learn, and MySQL. |
| **Main Findings** | The proposed approach achieved more than 94% accuracy in classifying SQL Injection attack types and intentions. |
| **Limitation** | Performance depends on the quantity and quality of training data and the integrity of the data processing process. |
| **Relevance to Proposed Research** | Demonstrates the application of machine learning to SQL Injection classification and highlights the importance of dataset quality in ML-based detection. |
