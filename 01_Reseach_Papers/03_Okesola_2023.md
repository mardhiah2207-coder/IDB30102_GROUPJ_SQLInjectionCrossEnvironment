# Okesola et al. (2023)

| Item | Required Information |
|---|---|
| **Paper Title** | *Securing Web Applications Against SQL Injection Attacks: A Parameterised Query Perspective* |
| **Author(s)** | J. O. Okesola, A. S. Ogunbanwo, A. Owoade, E. O. Olorunnisola, and K. Okokpuji |
| **Year** | 2023 |
| **Research Problem** | The study investigates SQL injection vulnerabilities in web applications and how parameterised queries can reduce the risk of malicious input being interpreted as part of an SQL statement. |
| **Method / Technique** | Parameterised queries are used as a prevention technique by separating SQL query structure from user-supplied input. |
| **Dataset / Tools** | Web application SQL query context and parameterised query techniques. |
| **Main Findings** | Parameterised queries provide an important preventive mechanism against SQL injection by preventing user input from changing the intended SQL query structure. |
| **Limitation** | Parameterised queries mainly provide prevention at the application-development level and do not provide an ML-based mechanism for detecting or classifying SQL injection queries. |
| **Relevance to Proposed Research** | Provides evidence that traditional SQLi prevention techniques remain important. It establishes the traditional approach against which automated ML-based detection approaches can be considered. |
