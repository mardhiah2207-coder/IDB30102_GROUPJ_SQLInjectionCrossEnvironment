# Qbea’h et al. (2022)

| Item | Required Information |
|---|---|
| **Paper Title** | Diverse Approaches Have Been Presented To Mitigate SQL Injection Attack, But It Is Still Alive: A Review |
| **Author(s)** | M. Qbea'h, S. Alrabaee, M. Alshraideh, and K. E. Sabri |
| **Year** | 2022 |
| **Research Problem** | The study investigates why SQL Injection remains a significant threat despite the availability of various detection and mitigation approaches. |
| **Method / Technique** | The study conducts a literature review of SQL Injection attack types and compares static, dynamic, and machine learning-based mitigation approaches. |
| **Dataset / Tools** | Previous SQL Injection studies and security tools including SQLBlock, DIAVA, SQLMap, and Acunetix were reviewed. |
| **Main Findings** | The review identified six major SQL Injection types and found that existing ML techniques and security tools may not cover all types of attacks. |
| **Limitation** | Existing tools are often focused on specific environments, while manual and modified SQL Injection attacks can remain difficult to detect. |
| **Relevance to Proposed Research** | Supports the need for more comprehensive SQL Injection detection and evaluation across different datasets and environments. |
