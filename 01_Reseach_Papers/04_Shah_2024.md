# Shah et al. (2024)

| Item | Required Information |
|---|---|
| **Paper Title** | *Proposing Model for Classification of Malicious SQLi Code Using Machine Learning Approach* |
| **Author(s)** | I. Shah, N. Jhanjhi, and S. Brohi |
| **Year** | 2024 |
| **Research Problem** | The study investigates the classification of malicious SQL injection code using machine learning to distinguish malicious SQLi queries from legitimate queries. |
| **Method / Technique** | **Extra Trees** is used for feature selection to identify 25 important features, followed by a **Random Forest ensemble** for classification. |
| **Dataset / Tools** | **Kaggle SQL query logs**. Extra Trees and Random Forest are used for feature selection and classification. |
| **Main Findings** | The Random Forest ensemble achieved **98.9% accuracy** on the evaluated Kaggle query logs. |
| **Limitation** | The evaluation is based on a particular Kaggle dataset. Therefore, the reported performance does not demonstrate whether the model maintains similar performance on other SQL injection datasets. |
| **Relevance to Proposed Research** | **Highly relevant** because it directly uses Random Forest for SQLi classification. However, the study mainly evaluates one dataset. The proposed research extends this by evaluating Random Forest across **different SQL injection datasets** to investigate generalisation. |
