# Zhang et al. (2022)

| Item | Required Information |
|---|---|
| **Paper Title** | Deep Neural Network-Based SQL Injection Detection Method |
| **Author(s)** | Wei Zhang, Yueqin Li, Xiaofeng Li, Minggang Shao, Yajie Mi, Hongli Zhang, and Guoqing Zhi |
| **Year** | 2022 |
| **Research Problem** | The study investigates how deep learning can improve SQL Injection detection while reducing dependence on manual feature extraction. |
| **Method / Technique** | The proposed SQLNN uses word-vector representation, TF-IDF, sparse matrices, multiple hidden layers, ReLU activation, and Dropout. |
| **Dataset / Tools** | Kaggle SQL Injection dataset containing 30,919 SQL statements, divided into 70% training and 30% testing data. |
| **Main Findings** | The SQLNN model achieved more than 96% accuracy and outperformed KNN, Decision Tree, and LSTM based on accuracy, precision, recall, and F1-score. |
| **Limitation** | The evaluation is mainly based on one dataset that provides limited evidence of how the model performs across different datasets. |
| **Relevance to Proposed Research** | Demonstrates strong ML/DL performance on a specific dataset and supports the need to evaluate SQL Injection detection models across different datasets to assess generalisation. |
