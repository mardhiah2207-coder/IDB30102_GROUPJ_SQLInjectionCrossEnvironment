# Bouafia et al. (2023)

| Item | Required Information |
|---|---|
| **Paper Title** | Automatic Protection of Web Applications Against SQL Injections: An Approach Based On Acunetix, Burp Suite and SQLMAP |
| **Author(s)** | R. Bouafia, H. Benbrahim, and A. Amine |
| **Year** | 2023 |
| **Research Problem** | The study investigates how SQL Injection vulnerabilities can be automatically identified and exploited during security testing of web applications. |
| **Method / Technique** | The approach uses automated penetration testing through a four-step workflow involving scanning, interception, command generation, and exploitation. |
| **Dataset / Tools** | Damn Vulnerable Web Application (DVWA) was used as the testing environment. Tools included was Acunetix, Burp Suite, and SQLMap. |
| **Main Findings** | SQL Injection exploitation was successful at low, medium, and high security levels. SQLMap was also able to extract information and decrypt MD5 hashes. |
| **Limitation** | The evaluation focused mainly on DVWA, limiting evidence of effectiveness across different web applications and environments. |
| **Relevance to Proposed Research** | Provides a practical security testing baseline and demonstrates that SQL Injection vulnerabilities can remain exploitable despite application hardening. |
