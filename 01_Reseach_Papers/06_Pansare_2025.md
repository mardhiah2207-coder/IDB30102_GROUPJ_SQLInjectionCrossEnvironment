# Pansare et al. (2025)

| Item | Required Information |
|---|---|
| **Paper Title** | *Preventing SQL Injection Attacks with Machine Learning: A TF-IDF + XGBoost Approach* |
| **Author(s)** | S. S. Pansare, P. S. Nimbalkar, P. P. Mhaske, S. P. Kadam, G. P. Patil, and S. Angadi |
| **Year** | 2025 |
| **Research Problem** | The study investigates the use of machine learning to detect and prevent SQL injection attacks by identifying patterns within SQL queries. |
| **Method / Technique** | **TF-IDF** is used for feature extraction and **XGBoost** is used to classify SQL queries as benign or malicious. |
| **Dataset / Tools** | **30,000 SQL queries**, consisting of **15,000 benign and 15,000 malicious queries**. |
| **Main Findings** | The approach achieved **99.37% accuracy, 99.41% precision, 99.31% recall, and 99.36% F1-score**. |
| **Limitation** | The evaluation uses a specific balanced dataset. Therefore, the high performance may not necessarily be maintained on datasets with different distributions, attack patterns, or characteristics. |
| **Relevance to Proposed Research** | Demonstrates that ML models can achieve high SQLi detection performance on a specific dataset. It supports the proposed research by highlighting the need to determine whether strong performance can be maintained when the model is tested on **different datasets**. |
