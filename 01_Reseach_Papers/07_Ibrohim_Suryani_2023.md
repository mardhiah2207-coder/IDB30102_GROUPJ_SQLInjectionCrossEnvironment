# Ibrohim & Suryani (2023)

| Item | Required Information |
|---|---|
| **Paper Title** | Classification of SQL Injection Attacks Using Ensemble Learning SVM and Naïve Bayes |
| **Author(s)** | M. M. Ibrohim and V. Suryani |
| **Year** | 2023 |
| **Research Problem** | The study investigates the classification of SQL injection attacks and the challenge of distinguishing malicious SQL queries from legitimate queries accurately. |
| **Method / Technique** | The researchers use an ensemble learning approach that combines Support Vector Machine (SVM) and Naïve Bayes. Preprocessing includes duplicate removal, oversampling, case folding, and tokenization, followed by TF-IDF feature extraction. |
| **Dataset / Tools** | SQL injection query data with the techniques used that include preprocessing, TF-IDF, SVM, Naïve Bayes, and voting ensemble learning. |
| **Main Findings** | The ensemble approach achieved 92.9% accuracy in classifying SQL injection attacks. |
| **Limitation** | The performance depends on the quality and representation of the dataset and the selected TF-IDF features. Fixed feature representation may limit performance on different SQL injection patterns or datasets. |
| **Relevance to Proposed Research** | Demonstrates that ML-based classification can effectively detect SQLi. It supports the proposed use of ML while motivating further evaluation using Random Forest across different SQL injection datasets. |

## Reference

Ibrohim, M. M., & Suryani, V. (2023). *Classification of SQL injection attacks using ensemble learning SVM and Naïve Bayes*. 2023 International Conference on Data Science and Its Applications (ICoDSA), 230–236. https://doi.org/10.1109/ICODSA58501.2023.10277436
