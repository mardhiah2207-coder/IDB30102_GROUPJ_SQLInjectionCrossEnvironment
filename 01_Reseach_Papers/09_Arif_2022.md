# Arif et al. (2022)

| Item | Required Information |
|---|---|
| **Paper Title** | *Analysis of SQL Injection Attack Detection and Prevention on MySQL Database Using Input Categorization and Input Verifier* |
| **Author(s)** | A. A. S. Arif, R. Purwoko, N. Qomariasih, and H. Setiawan |
| **Year** | 2022 |
| **Research Problem** | The study investigates how SQL Injection attacks can be detected and prevented in web applications using MySQL databases. |
| **Method / Technique** | The study applies **Input Categorization** and **Input Verifier** techniques, supported by automatic and manual SQL Injection testing. |
| **Dataset / Tools** | **15 web applications with five different database characteristics** were evaluated using **SQLMap, PHP, MySQL, and localhost**. |
| **Main Findings** | Applications implementing the proposed detection and prevention technique successfully resisted the tested **Union-based, Error-based, and Blind SQL Injection attacks**. |
| **Limitation** | The study evaluates only one detection and prevention technique and covers a limited range of SQL Injection attack types. |
| **Relevance to Proposed Research** | Provides a **traditional input validation and verification baseline** for comparison with the proposed ML-based SQL Injection detection approach. |

## Reference

Arif, A. A. S., Purwoko, R., Qomariasih, N., & Setiawan, H. (2022). *Analysis of SQL injection attack detection and prevention on MySQL database using input categorization and input verifier*. 2022 IEEE 8th Information Technology International Seminar (ITIS), 190–194. IEEE Record 10010201.
