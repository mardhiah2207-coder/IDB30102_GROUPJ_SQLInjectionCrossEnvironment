# Li et al. (2024)

| Item | Required Information |
|---|---|
| **Paper Title** | Trident: Detecting SQL Injection Attacks via Abstract Syntax Tree-based Neural Network |
| **Author(s)** | Yuanlin Li, Zhiwei Xu, Min Zhou, Hai Wan, and Xibin Zhao |
| **Year** | 2024 |
| **Research Problem** | The study addresses the difficulty of detecting complex SQL injection attacks, particularly attacks that may evade conventional detection approaches. |
| **Method / Technique** | The study proposes Trident, an Abstract Syntax Tree (AST)-based neural network that uses tree-based positional embedding to capture the structural characteristics of SQL statements. |
| **Dataset / Tools** | A public SQL injection dataset and an adversarial sample dataset are used to evaluate the proposed approach. |
| **Main Findings** | Trident achieved an F1-score of 99.7% and demonstrated strong resistance against adversarial SQL injection samples while outperforming the baseline approaches. |
| **Limitation** | The AST-based neural network requires relatively high computational and memory resources, which may affect its practicality in lightweight deployment environments. |
| **Relevance to Proposed Research** | Demonstrates that advanced neural-network approaches can achieve high SQL injection detection performance. However, its computational requirements support the investigation of a simpler and lightweight ML model such as Random Forest across different datasets. |
