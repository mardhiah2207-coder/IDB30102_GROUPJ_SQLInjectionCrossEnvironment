# Falowo et al. (2025)

| Item | Required Information |
|---|---|
| **Paper Title** | Machine Learning-Based Detection and Classification of SQL Injection Attacks Using a Stacking Ensemble Model |
| **Author(s)** | G. Falowo, B. O. Olorunfemi, A. E. Adeniyi, O. B. Abosede, and E. Ogbuju |
| **Year** | 2025 |
| **Research Problem** | The study investigates how machine learning can be used to detect and classify SQL injection attacks while achieving reliable classification performance. |
| **Method / Technique** | A stacking ensemble model using Decision Tree, Random Forest, and Logistic Regression as base learners, followed by a meta-classifier. |
| **Dataset / Tools** | Approximately 33,000 SQL queries. The study uses Decision Tree, Random Forest, Logistic Regression, and stacking ensemble learning. |
| **Main Findings** | The stacking ensemble demonstrated strong SQL injection detection and classification performance while balancing precision and recall. |
| **Limitation** | The use of multiple classifiers and a meta-classifier increases model complexity compared with a single ML model. Feature extraction and ensemble processing may also introduce additional processing requirements. |
| **Relevance to Proposed Research** | Demonstrates the usefulness of Random Forest within an ensemble model. The proposed research simplifies the approach by focusing on a single Random Forest model and evaluating its consistency across different SQLi datasets. |
