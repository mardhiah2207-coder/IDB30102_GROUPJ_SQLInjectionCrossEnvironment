# Liu & Dai (2024)

| Item | Required Information |
|---|---|
| **Paper Title** | Deep Learning in Cybersecurity: A Hybrid BERT–LSTM Network for SQL Injection Attack Detection |
| **Author(s)** | Yixian Liu and Yupeng Dai |
| **Year** | 2024 |
| **Research Problem** | The study addresses the challenge of detecting different types of SQL injection attacks, including complex, encoded, and bypass payloads. |
| **Method / Technique** | A hybrid BERT-LSTM network is proposed, where BERT captures contextual information from SQL statements and LSTM processes sequential features for classification. |
| **Dataset / Tools** | The study uses the Httpparams dataset containing 10,852 malicious SQL injection statements and 19,304 normal requests, divided into training, validation, and testing sets. |
| **Main Findings** | The proposed model achieved 97.3% accuracy, 96.3% precision, 96.2% recall, and 95.8% F1-score. |
| **Limitation** | The hybrid BERT-LSTM architecture has relatively high model complexity and computational requirements. Challenges also remain when dealing with encoded payloads and other injection types. |
| **Relevance to Proposed Research** | Shows that deep learning can achieve strong SQL injection detection performance. Its complexity supports the investigation of a more lightweight ML approach such as Random Forest for detection across different datasets. |
