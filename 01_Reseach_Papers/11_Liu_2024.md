# Liu et al. (2024)

| Item | Required Information |
|---|---|
| **Paper Title** | SQLStateGuard: Statement-Level SQL Injection Defense Based on Learning-Driven Middleware |
| **Author(s)** | Xin Liu, Yuanyuan Huang, Tianyi Wang, Song Li, Weina Niu, Jun Shen, Qingguo Zhou, and Xiaokang Zhou |
| **Year** | 2024 |
| **Research Problem** | The study addresses the need for effective statement-level SQL injection detection and defense while maintaining practical performance in web application environments. |
| **Method / Technique** | The study proposes SQLStateGuard, a learning-driven middleware framework using SQLSG-Net for statement-level SQL injection detection. The approach applies NLP-based processing and Gated Linear Units (GLU). |
| **Dataset / Tools** | Two SQL injection datasets are used. Dataset I contains 75,000 normal and 74,555 malicious statements, while Dataset II contains 79,316 normal and 71,757 malicious statements. |
| **Main Findings** | The approach achieved 100% accuracy, precision, recall, and F1-score for binary classification on Dataset I and approximately 99.97% accuracy, precision, recall, and F1-score on Dataset II. |
| **Limitation** | The middleware introduces additional latency and integration complexity. Deployment may also require schema synchronization between the application and database. |
| **Relevance to Proposed Research** | Demonstrates that learning-based SQL injection detection can achieve high performance across more than one dataset. This supports the importance of evaluating whether an ML model can maintain consistent performance across different SQL injection datasets. |
