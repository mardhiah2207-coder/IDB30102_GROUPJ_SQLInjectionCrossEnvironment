# Paul et al. (2024)

| Item | Required Information |
|---|---|
| **Paper Title** | SQL Injection Attack: Detection, Prioritization & Prevention |
| **Author(s)** | Alan Paul, Vishal Sharma, and Oluwafemi Olukoya |
| **Year** | 2024 |
| **Research Problem** | The study addresses the challenges of detecting, prioritizing, and preventing SQL injection attacks in web and network environments. |
| **Method / Technique** | A hybrid CNN-LSTM approach called SQLR34P3R is used for SQL injection detection, prioritization, and prevention. |
| **Dataset / Tools** | 457,233 benign and malicious network traffic samples and 70,023 SQL injection and benign payload samples. The study also uses DVWA, Vulnado, Wireshark, and SQLMap. |
| **Main Findings** | The hybrid CNN-LSTM approach achieved an average F1-score of approximately 97% for SQL injection detection and filtering. |
| **Limitation** | The approach introduces additional processing latency and integration complexity. Deployment also requires schema synchronization between application and database components. |
| **Relevance to Proposed Research** | Demonstrates the effectiveness of machine learning for SQL injection detection while highlighting practical deployment challenges. It supports the need to evaluate ML detection across different SQL injection datasets. |
