# Toktassyn & Al-Hubaishi (2026)

| Item | Required Information |
|---|---|
| **Paper Title** | Enhanced SQL Injection Detection Using Advanced Feature Engineering and Machine Learning Ensemble Methods |
| **Author(s)** | A. Toktassyn and M. Al-Hubaishi |
| **Year** | 2026 |
| **Research Problem** | The study investigates how advanced feature engineering and machine learning ensemble methods can improve the detection of malicious SQL queries. |
| **Method / Technique** | The study uses statistical, syntactical, and entropy-based features together with TF-IDF. Multiple ML models are evaluated, including Random Forest and Gradient Boosting. |
| **Dataset / Tools** | IEEE DataPort dataset containing 244,068 SQL queries, consisting of 136,740 malicious and 107,328 legitimate queries. |
| **Main Findings** | Random Forest achieved 99.3% accuracy using an 80:20 train-test split and 99.1% accuracy using a 50:50 split. Gradient Boosting also achieved performance above 99%. |
| **Limitation** | The evaluation mainly uses one dataset. Adversarial attacks and real-world deployment conditions were not evaluated. Therefore, the results do not demonstrate how the model would perform across different datasets. |
| **Relevance to Proposed Research** | Highly relevant because Random Forest achieved strong performance, but the study evaluates it mainly using one dataset. The proposed research addresses this limitation by testing Random Forest across different SQL injection datasets and comparing Accuracy, Precision, Recall, F1-score, and Processing Time. |
