# Zulu et al. (2024)

| Item | Required Information |
|---|---|
| **Paper Title** | *Enhancing Machine Learning Based SQL Injection Detection Using Contextualized Word Embedding* |
| **Author(s)** | Janet Zulu, Bonian Han, Izzat Alsmadi, and Gongbo Liang |
| **Year** | 2024 |
| **Research Problem** | The study investigates how improved representation of SQL query information can enhance machine learning-based SQL Injection detection. |
| **Method / Technique** | The study compares **contextualized and non-contextualized word embeddings** with several ML algorithms, including Neural Networks, KNN, **Random Forest**, and Logistic Regression. |
| **Dataset / Tools** | A **SQL Injection query dataset** was used to evaluate different combinations of word embeddings and classification algorithms. |
| **Main Findings** | Contextualized word embeddings achieved **more than 99% accuracy** across the evaluated classification algorithms and reduced model training time by approximately **31 times**. |
| **Limitation** | The study focuses mainly on embedding representation and model training rather than directly evaluating **cross-dataset generalisation**. |
| **Relevance to Proposed Research** | Shows that **feature representation can influence ML-based SQL Injection detection** and provides supporting evidence for evaluating Random Forest using different SQL Injection datasets. |

## Reference

Zulu, J., Han, B., Alsmadi, I., & Liang, G. (2024). *Enhancing machine learning based SQL injection detection using contextualized word embedding*. Proceedings of the 2024 ACM Southeast Conference, 211–216. https://dl.acm.org/doi/epdf/10.1145/3603287.3651187
