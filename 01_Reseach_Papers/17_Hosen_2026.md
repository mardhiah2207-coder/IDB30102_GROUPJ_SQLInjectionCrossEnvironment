# Hosen et al. (2026)

| Item | Required Information |
|---|---|
| **Paper Title** | Interpretable SQL Injection Detection: Lightweight Decision Trees with SHAP-Enhanced Deployment |
| **Author(s)** | S. Hosen, A. A. M. Zihan, and N. Mamun |
| **Year** | 2026 |
| **Research Problem** | The study investigates the need for lightweight and interpretable machine learning models for SQL injection detection. Complex models may provide strong performance but can require more computational resources and may be difficult to interpret. |
| **Method / Technique** | A lightweight Decision Tree approach combined with TF-IDF feature extraction and SHAP for model interpretation. |
| **Dataset / Tools** | Synthetic and real-world SQL injection datasets, with external testing using a Kaggle dataset. Techniques include TF-IDF, Decision Tree, and SHAP. |
| **Main Findings** | The model achieved 98.31% training accuracy and 97.52% external accuracy. The study also reported low latency and used SHAP to provide explanations for classification decisions. |
| **Limitation** | The study has limited coverage of highly complex SQL injection payloads and requires further evaluation in more diverse and distributed environments. |
| **Relevance to Proposed Research** | Important because it demonstrates the value of external dataset evaluation. It supports the proposed research focus on testing Random Forest across different SQLi datasets to investigate whether detection performance remains consistent. |
