# Literature Review Analysis Table

| Author & Year | Research Problem | Method / Technique | Dataset / Data Source | Main Finding | Limitation | Relevance to Proposed Research |
|---|---|---|---|---|---|---|
| Kini et al. (2022) | Detection of SQL Injection attacks | Aho-Corasick algorithm | SQL Injection query/payload data | Achieved 90.23% detection accuracy | Pattern-based detection may have limitations against modified or unseen attacks | Provides evidence of traditional pattern-based SQLi detection |
| Ibrohim & Suryani (2023) | Classification of SQL Injection queries | TF-IDF + SVM + Naïve Bayes ensemble | SQL query dataset | Achieved 92.9% accuracy | Performance depends on dataset and feature representation | Supports the use of ML for SQLi classification |
| Shah et al. (2024) | Automated SQL Injection detection | Machine learning-based approach | SQL Injection dataset | Reported high detection performance | Evaluation is dependent on the dataset used | Demonstrates the effectiveness of ML-based SQLi detection |
| Zulu et al. (2024) | SQL Injection detection using contextual information | RoBERTa / contextualised embeddings | SQL Injection data | Approximately 99% accuracy | Higher model complexity and computational requirements | Shows the potential of advanced DL models |
| Liu & Dai (2024) | Detection of SQL Injection attacks | BERT-LSTM | SQL query/payload dataset | F1-score of 95.8% | Complex architecture and resource requirements | Demonstrates strong DL-based classification performance |
| Li et al. (2024) | Robust SQL Injection detection | AST-based Trident | SQL query data | F1-score of 99.7% | More complex structural analysis | Shows that structural features can improve detection |
| Pansare et al. (2025) | SQL Injection classification | TF-IDF + XGBoost | 30,000 SQL queries | 99.37% accuracy and 99.36% F1-score | Performance is evaluated based on a specific dataset | Strong evidence for ML-based SQLi detection |
| Falowo et al. (2025) | Detection/classification of SQL Injection attacks | Machine learning approach | SQL Injection dataset | Demonstrated ML-based detection capability | Dataset-specific evaluation | Supports investigation of ML generalisation |
| Hosen et al. (2026) | Explainable SQL Injection detection | Decision Tree + SHAP | SQL Injection data + external dataset | 98.31% training accuracy and 97.52% external accuracy | Further cross-dataset evaluation is still needed | Directly supports the research focus on generalisation |
