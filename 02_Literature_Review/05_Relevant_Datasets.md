# Relevant Datasets

## 1. Dataset Requirements

The proposed research requires SQL Injection datasets that contains both legitimate and malicious SQL queries or payloads. Different datasets are important because the main research focus is to investigate the generalisation of SQL Injection detection across different datasets.

## 2. Potential Dataset Sources

Relevant sources identified from previous research include:

- Kaggle SQL Injection datasets
- Public SQL query datasets
- GitHub SQL Injection datasets
- OWASP-related vulnerable application data
- SQL Injection payload datasets
- HTTP request datasets containing SQL Injection attempts

## 4. Dataset Selection Criteria

The datasets selected for the proposed research should:

1. Contain legitimate and malicious SQL queries.
2. Be publicly accessible or legally usable for research.
3. Provide sufficient samples for machine learning.
4. Have identifiable labels.
5. Differ sufficiently in characteristics to support cross-dataset evaluation.

## 5. Relevance to Research Gap

Using more than one SQL Injection dataset allows the proposed research to investigate whether the Random Forest model maintains consistent detection performance when there is any change of the data characteristics.

The final datasets will be confirmed during the methodology and implementation stages.
