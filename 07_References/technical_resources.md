# Technical Resources

This file lists the main software, libraries, and technical resources that will support the implementation of the proposed SQL Injection detection model.

## Python

Python will be used as the main programming language for data preprocessing, feature extraction, model development, and evaluation.

## Scikit-learn

Scikit-learn will be used for machine learning implementation. It will support TF-IDF feature extraction, Random Forest classification, dataset splitting, and calculation of evaluation metrics.

## Pandas

Pandas will be used to load, organise, clean, and process the datasets before model training and evaluation.

## NumPy

NumPy will support numerical operations required during data processing and model evaluation.

## Main Technical Components

The proposed implementation will mainly use:

- TF-IDF Vectorizer for text feature extraction
- Random Forest Classifier for SQL Injection detection
- Train-test split for baseline evaluation
- Accuracy, Precision, Recall, F1-score, and False Positive Rate for performance evaluation

Official documentation and relevant technical references will be used during the implementation stage.
